This repository is dedicated to the first PoC implementation of SPIDER and SPIDER-IBS.

On a SageMath terminal, command `sage SPIDER_test.py` aloows to run the SPIDER signature program, while `sage SPIDER_IBS.sage` allows to run the SPIDER-IBS program.

We run the cod on `SageMath 10.7`

We use the [SQIsign-PRISM repository](https://github.com/KULeuven-COSIC/sqisign_prism_v2) for our implementation.
